## INDmoney Net Worth Log v1.3.0

**Updates now come to you.** After this one update, new dashboard features arrive on their own: no more downloading zips.

### If you installed an earlier version
1. Download `indmoney-networth-log.zip` below.
2. Add it to Claude: **Plugins → Add → Upload plugin** (app) or **Customize → Skills → + → Upload a skill** (web). It replaces the old copy.
3. In a new chat, say: **"Update my INDmoney net worth log."** Your history is kept.

### New in 1.3.0
- The dashboard updates itself
- The morning task saves everything INDmoney reports, so new features can use days already logged
- Rare task changes: one click to copy, one paste into Claude
- Anonymous daily usage count (date and version only)

### Also since 1.0.0
- Loans and credit cards listed one by one; switch to show assets before liabilities
- Each bank account's balance and change
- **+** to expand "Other assets", ⓘ notes on the columns
- Morning summary flags big bank-balance moves and card dues
